# T0 repository intelligence

Use this only for a scoped repository fact. Start with the project profiler
when useful, then choose the cheapest direct mechanism: exact file read, exact
text search, configured project LSP, or declared dependency metadata.

Keep results revision-stamped, source-anchored, compact, and explicitly
non-authorizing. Direct inspection is authoritative for observed text and
metadata. Structural relationships that direct mechanisms cannot establish
remain unresolved; do not invent Graphify output or promote inferred edges.
Optional Graphify is a read-only, explicitly approved future candidate and
never a startup, hook, archive, or authorization dependency.

Do not browse the web, write target files, build a persistent map, or turn
repository evidence into a decision, requirement, task, or authorization.
